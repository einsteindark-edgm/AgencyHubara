# Architectural decisions

Lightweight ADRs (Architectural Decision Records) added by any agent that makes a decision worth keeping. Each ADR is 5-10 lines.

Template:

```
## ADR-NNN · <short title>
- **Date**: YYYY-MM-DD
- **By**: <agent or human>
- **Context**: <why this decision is needed, in one sentence>
- **Decision**: <what was decided>
- **Consequences**: <implications, in 1-2 lines>
```

Numbering is sequential. Append, never edit (if you change your mind, write a new ADR that supersedes the old one and reference it: `Supersedes ADR-007`).
